二、问题诊断

2.1 A 类 · 结构与布局（致命/严重）

#问题坐标证据 / 表现后果级别
A1表头与表体列宽不一致，出现"影子第四列"表头行1 列C：x 439.5–713.0（273.5pt）；数据行 列C：x 439.5–605.8（166.3pt）。两表同病。表格网格断裂；放大投影时一眼可见"最后一行多一块"；图片被误读为数据列。致命
A2列宽严重失衡表二：行首列 198.9 / A 115.3 / B 111.7 / C 166.3。我方列比竞品列宽 49%。视觉上像"我方列被特意放大"，有刻意对比之嫌；竞品列 111.7pt 装不下「±1.5%~±3%」这类长串。严重
A3两张表的列起点对不齐表一行首列 13.5–210.6（197.1）；表二行首列 13.5–212.4（198.9）。A 列起点 210.6 vs 212.4。上下两表的竖向网格线错开 1.8pt，远看是"两条不连续的竖线"。一般

A5两表标题缩进不一致且不与表格左缘对齐表一标题 x 起点 263.6；表二标题 x 起点 278.6；表格左缘 x=13.5。标题像"浮在表上方中间"，与表格无视觉锚定关系。一般

2.2 B 类 · 字段语义与归属（致命/严重）

#字段问题为什么是问题级别
B1表一整表按项目定位（PEEK 只是应用场景），材料对比表不应占据主页面上半屏，且视觉面积大于装备表。P12 是"项目优势"的对标页，上半屏被材料表占领，直接推翻"全装备叙事"。评委的第一落眼点是表一。致命
B2适用预热方式归属错误：预热方式是装备属性，不是材料属性，却放在材料对比表里。威格斯 450FC30 是粉末牌号，粉末本身没有"单区整体预热"这一说；这是把机器特性安到粉末头上。致命
B3适用预热方式字段冗余：与表二「闭环控制机制」「多区动态解耦」语义高度重叠。同一能力在两页两表里说两遍，且措辞不同（动态解耦 / 动态闭环）。严重
B4厂商及系统配置命名不清：「系统配置」指什么系统？控温系统？整机？与表二「厂商及装备牌号」不是同一概念却并列呈现。两表行首列名不一致（系统配置 vs 装备牌号），读者需自行推断它们其实是"行名/指标名列"。严重
B5干摩擦系数缺测试四要素：对偶材料、载荷、速度、温度；无执行标准。术语守门规则 L2 机理量——不标四要素的摩擦系数在学术上无意义，专家一问即破。致命
B6宽温域适应性"稳定"未定义：是摩擦系数稳定？强度保持率？尺寸稳定？-150℃~150℃ 上限 150℃ 已越过 PEEK 的 Tg（约 143℃）。150℃ 高于 Tg 时 PEEK 已软化，"稳定"若指承载/尺寸，需要极强证据；目前没有任何限定。致命
B7成形构件批次强度波动命名与主语失真：参考答辩 P41/P45 的原始事实是「多次打印拉伸试样最高强度最大差值由 16.03MPa 降至 4.04MPa」，是试样级统计量；本表升格为"构件批次强度波动"。把拉伸试样的批间极差，泛化为"成形构件批次强度波动"——术语跨层（L3 试样 → 构件）。评委会问"哪个构件？多少件？同一批次还是跨批次？"致命
B8闭环控制机制与 P4 直接冲突：P4 说 EOS「8 区单向温控」「在线激光功率反馈调节」；P12 说 EOS P800「开环人工调参」。同一份材料里对同一竞品给出两种相反的技术判断，任何一处被追问都会崩。致命

2.5 E 类 · 与前后页的一致性

  • P4 ↔ P12 冲突：P4「原位测温响应 · 国外：在线激光功率反馈调节」vs P12「EOS P800：开环人工调参」。必须二选一或加限定语。
  • P6 ↔ P12 冲突：P6「腔体温度突破 400℃」 vs P12「400~420℃」。建议统一为 400℃。
  • P10 ↔ P12 重复：P10 已有"整体温度标准差降低57%／区域温差降低63%／成品率 <30%→>85%／翘曲率 <0.3%"，P12 右侧 KPI 卡又列一遍 57%、48%、96%，形成冗余；而 P10 的"成品率、翘曲率"反而没进对标表。
  • P12 图片复用：表一右侧竖图（xref 8094）与表二右侧竖图（xref 8303）同时出现在 P22，在 P22 上分别位于"材料""装备"图例正下方——说明这两张图确为材料图与装备图，归属正确但缺图签。
  • 工艺路线未声明：EOS P800（激光烧结）、UT252P（SLS）、LPBF-400（LPBF）三条路线被放进同一张"同类型装备对比"表，却没有工艺路线这一行。这是整张表最大的可比性漏洞。

四、结构调整方案

4.1 总原则

  1. 一页一主表：P12 只保留一张装备对标表；材料对比整表移出（建议移到 P9 作为"应用场景"小卡，或放备查附录）。
  2. 先声明可比性，再比数字：新增「工艺路线」行与「口径与来源」列，把"公开资料"与"我方实测"彻底分开标注。
  3. 绝对值进表，相对改善进卡：主表只放可直接比较的绝对量；"降低57%、降低48%、升至96%"这类相对量放到右侧改善卡，并写出基线。
  4. 数值口径三统一：同行三家同为点值、或同为区间、或同为上下限，不允许混用；比较方向（越大越好/越小越好）在行名后标注箭头。
  5. PEEK 降级为场景条：页面底部保留一条窄条，写明"当前已验证材料体系"，让材料回到它该在的位置。

七、一句话结论

P12 的问题不在"数据不够漂亮"，而在表格本身不成立：表头与表体列宽错位、两表排版语言不同、同一行里点值与区间混用、竞品用下界我方用上界、竞品数字无来源、材料属性与装备属性同表、工艺路线不同却被当作同类对标。
改法不是修数字，是重建表结构：一页一表 → 先声明工艺路线与来源口径 → 只放同类型可比的绝对量 → 相对改善放进带基线的卡片 → PEEK 降为底部场景条。
