## 使用方法

1. 任何关于"塑成非凡"项目的工作（PPT、材料/装备技术论证、商业模式、答辩演练、检索求证），
   先看 `03-专家团与技能路由/00-SKILL运用指南.md`，它是总纲。
2. 遇到重要分岔点（例如"背景要不要放材料对比还是装备对比""第四页删不删"），调用
   `00-底座准则/内阁决策法.md` 的五方会审法。
3. 任何对外文案（PPT 文案、路演稿、汇报文档），出稿前过一遍 `00-底座准则/Stop-slop去AI味.md` 与
   `Humanizer人性化写作.md`，禁止空洞排比、破折号堆砌、"赋能/闭环/抓手"式黑话。
4. 记忆系统常驻：项目事实与阶段性结论写入仓库根目录 `.memory/PROJECT_FACTS.md`、
   `.memory/LEARNINGS.md`、`.memory/ERRORS.md`，每次交互后随手更新，不等任务结束才写。
