## 2. 第二页（现 P3）改造工单

### 2.1 顶部主旨句（原文→建议文）

- 原文：研发自润滑复合材料与高温LPBF增材制造装备是提升高端装备运动可靠性的关键手段
- **主案**：自润滑复合材料突破均质性能极限，LPBF 制造自由度让「不同位置不同性能」成为现实（约 40 字，与现句栏宽相当）
- 备案（更短）：PEEK 基自润滑复合材料＋梯度成形：突破均质极限，LPBF 自由度支撑分区赋能

### 2.2 左卡「PEEK 及 PEEK 基自润滑复合材料」（保持两卡片骨架）

- 块1 PEEK 优势：**原样保留**（「塑料之王」＋自润滑免维护/高强度高韧性/耐高温耐腐蚀三标签＋黑白粒料实拍）。
- 块2 复合材料优势：结构保留（基体/填料＋按需定制），**底部加一行金色量化优势条**：
  > 干摩擦系数 0.05～0.11 · 磨损率 1.2×10⁻⁵mm³/N·m · 拉伸强度 >120MPa
  > 脚注小字：注：比较国内外头部企业产品性能（与 P11 同口径，数字源 PDF P11/P6）
- 填料四宫格照片（PTFE/石墨/MoS₂/h-BN）可缩为两枚以让行高，非必改。

### 2.3 右卡重排（原「传统成形工艺＋LPBF 装备」→「梯度成形＋LPBF 自由度」）

- 右卡标题原文：复合材料一体化成形——LPBF增材制造装备
  → 建议：**突破均质极限——梯度构件成形与 LPBF 制造自由度**
- **上块·梯度构件成形**（S10）：
  - 标题：梯度构件成形——突破均质构件性能极限
  - 正文两行：齿面＝自润滑·耐磨·耐温；齿芯＝高强度·抗冲击·轻量（与现 P2 齿面/齿芯批注同语，形成「P2 提问→P3 回答」闭环）；
    金句：按功能分区、按工况赋能，不同位置不同性能。
  - 配图双档：**图版**＝`03-素材库/第二页配图/候选-AI示意-分区梯度打印齿轮剖面.png`（角标「分区梯度机制示意」，不得称实拍）；**形状版**＝PPT 原生：灰齿轮＋金色外圈批注＋蓝色内芯批注（与 P2 现有齿面/齿芯视觉同款）。
- **下块·LPBF 自由度**（S11）：
  - 标题：LPBF——制造自由度更高
  - 正文：逐层选区熔化，一体化成形高精度复杂构件（沿用现右卡原句）；方向性扫描策略可生成复杂拓扑与梯度微结构（沿用现 P10 原文口径）。

## 3. 新增装备页工单（插于第二页后，全篇第 4 页，22→23 页）

### 3.1 页眉与主旨句
- 页眉栏目：项 目 背 景（保持系列风格）
- **主旨句主案**：PEEK 成形难点多、传统加工劣势固有，高温 LPBF 一体化成形破题（33 字）
- 备案：为什么是高温 LPBF：成形难、加工难，一体化成形是唯一破题方向——⚠️「唯一」属绝对化词，**禁用**，仅备案对比用，实际请用主案。

### 3.2 三横卡（风格对齐现 P5 三栏）

**卡1 PEEK 材料成形难点**（S4）
- 标题：高熔点 PEEK 成形，道道是坎
- 四条（数字均源团队实测/台账）：
  1. 熔点≈343℃、烧结窗口窄，粉床预热须贴近熔点精控，依赖高温腔体（口径：腔体上限 400℃＝设备能力上限，与 P9 谱系条一致）；
  2. 热累积效应：逐层积热→翘曲＋粉层开裂；
  3. 温场实测：局部过热至 345℃；
  4. 功率变化→孔洞/粗糙堆积。
- 配图（**与现 P2 不重图**，用库内未上页团队一手素材）：
  - `03-素材库/第二页配图/★核心-粉末床3D热力扫描图(自研设备真实数据).jpg`
  - `03-素材库/第二页配图/现象证据-实测温度场热力图_条纹热累积(自研设备真实数据).png`
  - `03-素材库/第二页配图/现象证据-团队实测平整试样对照(原PPT自带).jpg`

**卡2 传统加工劣势**（S5）
- 标题：传统路线，「形」与「材」都受限
- 三条：
  1. 热压/注塑成形：无法实现功能结构一体化，构件精度低（沿用现 P3 原句＋沿用现 P3 热压/注塑两图）；
  2. 熔融沉积（FDM）：层纹与界面弱明显，致密与精度不足（沿用现 P3 FDM 图）；
  3. CNC 减材：复杂型腔/内部流道「削」不出来，材料利用率低（**新增**真实照片：`03-素材库/第一页配图/传统加工受限-CNC复杂型腔铣削实拍2.jpg`、`传统加工受限-CNC数控加工中心实拍1.jpg`；来源为外部检索存档，授权由团队确认，图注「传统减材加工示意」）。
- 收口句：模具成形受「形」限、减材制造受「削」限——复杂一体化＋材料分区，两者都给不了。

**卡3 → 高温 LPBF 一体化成形破题**（S3）
- 标题：高温 LPBF：一体化成形高精度复杂构件
- 三条：
  1. 激光粉末床熔融，逐层选区熔化，适配定制化生产（沿用现 P3 原句）；
  2. 自研高温 LPBF 智能成形装备：独立控温＋预热温度场仿真（P6 原文）；腔体上限 400℃，覆盖 PEEK/PEK/PI 等高熔点聚合物（与 P9 谱系条互证）；
  3. 承上启下：上接第二页「梯度与自由度」，下启 P9 装备优势页。
- 配图：`03-素材库/第二页配图/★核心-自研高温LPBF成形装备实拍(西交大HT-SLS+展板参数).jpg`（展板参数：幅面 320×320×300mm｜腔体上限 400℃｜激光 60W）＋`03-素材库/第一页配图/LPBF原理图-装备结构原理示意图(注意核实来源).png`（图注「原理示意，来源待核」）。
- ⚠️ 展板设备名为 HT-SLS，与全篇 LPBF 为两套命名：页面不展开，缝合口径放答辩稿（总方案 v3 已定）。
