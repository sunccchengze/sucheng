# 0902 P9「多材料成形能力」突显方案

> 任务（孙承泽 0902 原话）：要突出装备，就得突出这台 3D 打印机还可以**打印除 PEEK 外其他的高熔点材料**。
> 现在只有一句"适用于高熔点聚合物如PEEK、PI、PPS"，太不突出。
> 交付方式：本方案只出文案与版式工单，不动 PPT/PDF（沿用 0901 轮确认的角色边界）。

## 0. 三句话结论

1. 现句是"规格书语言"——16pt 一行字挤在指标卡顶部，而它本该承担全页最值钱的平台叙事：**LPBF-400 不是 PEEK 专用机，是覆盖 280–390℃ 熔点谱带的通用高温成形平台**。
2. 推荐组合＝**方案B（卡内"材料-熔点谱系条"，PPT 原生形状）＋方案C（页底金色结论横幅联动改 1 字增 3 字）**，不动任何图片、零 AI 配图，约 20 分钟可落地；赶时间用快案＝方案A+C（两处纯改字）。
3. 两条红线：400℃ 只能写"**腔体控温上限**"（前轮判例：PEEK 熔点≈343℃，"预热 400℃"是物理错误）；PI/PEK 在拿到实证样件前只能用"**可成形/温域覆盖**"能力句式，禁写"已实现打印"。另因 P9 引出"腔体上限"，**P11 行名「最高预热温度」必须同批等长改「腔体最高温度」**（前轮 R3 遗留，本轮不改就是跨页打架）。

## 1. 为什么要改——叙事逻辑

- **装备三问对照**（总方案v3 收口原则）：P9 现在"谁在做事"（多区域协同温控）与"做到什么程度"（57%/63%/<30%→>85%/<0.3%）都强，唯独"**凭什么赢的边界在哪**"缺位——而"能打除 PEEK 外的高熔点材料"正是 400℃ 腔体上限的直接兑换。
- **数据底座现成**：P11 对比表已写 LPBF-400 腔体 400℃ vs EOS P800 385℃ vs 华曙 UT252P 340℃。按公开工艺口径"粉床预热取熔点后 10–20℃"：
  - UT252P 340℃ → 只覆盖到 PEEK 级；
  - P800 385℃ → 够到 PEK(365℃)，压不住热塑性 PI(≈388℃)；
  - **LPBF-400 400℃ → 全谱带覆盖，且高段（365–390℃）为三家唯一**。
  这就是"多材料能力"的定量根源，P9 与 P11 天然互证，只差 P9 把参数翻译成能力语言。
- **商业叙事红利**：PEEK 专用机＝定制设备；通用高温平台＝平台型装备——市场天花板、抗单一材料周期、装备销售复购（P18 四条盈利线之设备线）全部被这一条撑起来。与 P8 材料端不冲突：材料产品线仍聚焦 PEEK 基（材料是壁垒），装备谱系通用（装备是产品）——正是"材料×装备双自主"的分工表达。
- **评委心理**：一句话"适用于…"是被动兜底；一条可视化谱系条是主动亮牌。前者像规格书参数，后者像能力宣言。

## 4. 三个方案

### 方案A｜快案：一行纯文字替换（2 分钟，零版式动作）

| 编号 | 原文 | 建议文 | 字数对照 |
|---|---|---|---|
| A1 | 适用于高熔点聚合物如PEEK、PI、PPS（21） | **不止PEEK：可成形PEK、PI等更高熔点聚合物**（24，+3） | 近似等长，直接替换 |
| A2 | 同上 | 不止于PEEK——通用高温多材料LPBF成形平台（24，+3） | 备选，平台感更强、具体材料名消失 |

- 优点：零风险。缺点：还是一行字，"突出"效果有限——**只建议在完全不动版式的场合使用**。

### 方案B｜主案：卡内「材料-熔点谱系条」（15–20 分钟，PPT 原生形状，无新图）

把现句一行字升级为一条可视化谱系，四枚实芯片＋一枚虚线"上限芯片"：

```
┌ 右下指标卡 [588,349 → 927,486] ──────────────────────────┐
│  不止PEEK：可成形材料谱系          ← 12pt 白，标签行        │
│  [PPS 280℃][PEEK 343℃][PEK 365℃][PI 388℃] ┊[腔体上限 400℃] │
│   ↑实芯片×4                                        ↑虚线芯片 │
│  整体温度标准差降低57%   ← 四指标原样保留，行距 28→26pt      │
│  区域温差降低63%                                           │
│  成品率<30% → >85%                                         │
│  成形翘曲率<0.3%                                           │
└──────────────────────────────────────────────────────────┘
（可选 8.5pt 尾注：熔点取公开TDS中位值，随牌号略有浮动）
```

**制作规格（照做即可）：**

| 元素 | 规格 |
|---|---|
| 标签行 | 12pt 白色，文本框放原句位置；文案三选一：**L2「不止PEEK：可成形材料谱系」**（首选，14字）／L3「通用高温平台·多材料成形谱系」（15字）／L1「可成形材料谱系（按熔点）」（13字） |
| 实芯片×4 | 圆角矩形，高 26pt；宽 52pt，间隙 6pt；底色深蓝（取卡底加深，如 #0B2A4D），1pt 青描边（取页面线条青，如 #3FA9F5）；内两行：上行材质名 9pt 白，下行熔点 12pt 金（与 57%/63% 数字同金色） |
| 虚线"上限"芯片 | 同尺寸圆角矩形，**无底色、金色虚线描边**，内两行：「腔体上限」9pt 白／「400℃」12pt 金 |
| 排序 | PPS 280 → PEEK 343 → PEK 365 → PI 388 → 上限 400，升序即"能力爬坡"阅读动线 |
| 四指标 | 行距 28→26pt（腾出 8pt），字号不动；可选尾注 8.5pt 置于"成形翘曲率"行下（若挤则删） |

**空间账**（卡内纵向 137pt）：标签 16 + 芯片 26 + 间距 6 + 四指标 3×26+19 = 149 → 超支 12pt，由四指标行距 28→26（省 8pt）＋标签/芯片间距压缩（省 4pt）解决，**不动卡框**。若嫌挤：删标签行，芯片行直接替换原句（四指标行距不动，净需求 32pt，完全放下）。

**变体（备选）**：高端聚焦版＝去掉 PPS 芯片，只留 PEEK/PEK/PI＋上限（"直击最高熔点段"叙事；同时落实前轮 R2"删 PPS"建议）。**推荐仍保留 PPS**："宽谱带覆盖"才是平台叙事，且 PPS 从"被误标高熔点"变为"谱带低端点"，R2 的问题被版式自然消解。

### 方案C｜联动：页底金色结论横幅（2 分钟，改一处字）

| 编号 | 原文 | 建议文 | 字数对照 |
|---|---|---|---|
| C1 | 突破高温LPBF温场控制瓶颈，实现PEEK复合材料智能稳定成形（31） | **突破高温LPBF温场控制瓶颈，从PEEK到PI多材料智能稳定成形**（32，+1） | 首选：页底最显眼行完成"不止PEEK"定调，居中横幅余量充足 |
| C2 | 同上 | 突破高温LPBF温场控制瓶颈，实现PEEK基及高熔点聚合物智能稳定成形（35，+4） | 保守备选：不点名 PI，答辩口径最稳 |

- 页底横幅是评委最后一眼、也是全页 takeaway。"实现PEEK复合材料…成形"把装备钉死在单材料上，是全页最后一块"专用机"痕迹，必须联动。

### 组合建议

- **主案＝B＋C**：卡内可视化谱系立论 + 页底横幅定调，两处同讲一个信息，不重复不上头。
- 快案＝A1＋C1（两次改字，5 分钟）。
- **不建议 A/B/C 三处全上**：一页一个记忆点，三处齐改反而稀释；标题行保持不动（"多区域协同温度场智能调控"是本页差异点主语，塞"多材料"会稀释焦点）。

## 5. 红线与合规（改前必读）

1. **400℃＝腔体控温上限**，全篇禁止"预热 400℃/PEEK 预热 400℃"表述（台账判例：PEEK 熔点≈343℃，二者物理冲突；答辩实测 PEEK 预热 320/335℃）。谱系条中 400℃ 已由虚线芯片天然表达为"上限"，不要写进实芯片。
2. **能力句式 vs 实证句式**：PI/PEK/PPS 未交付实证样件前，只用「可成形／温域覆盖／具备…能力」；禁写「已实现 PI 打印／PI 构件量产」。（若团队有样件，见第 7 节 Q1 升级路径。）
3. **绝对化禁用**：不用"全覆盖／任意材料／万物可打"；"全球首创"维持 P9 现状不再扩散新宾语。
4. **跨页口径联动（本方案触发的必改项）**：P11 对比表行名「最高预热温度（℃）」→「**腔体最高温度（℃）**」，6 字等长。原因：P9 一旦出现"腔体上限 400℃"，P11 的"最高预热温度"就成了评委对照即见的物理矛盾（前轮 R3 遗留，本轮必须清）。
5. **不动本页其余内容**：20μm（仿真网格分辨率判例）、57%/63%（D40/D45 两套口径）、专利证书图内红框残留，均已在台账备案，属另行任务，本轮不顺手改（防改动面失控）。

## 8. 答辩弹药（对应本页新叙事）

- **Q：除了 PEEK，你们还打过什么？**
  - ①能力层：腔体上限 400℃＋多区域独立控温，覆盖 280–390℃ 熔点谱带；按"预热取熔点后 10–20℃"公开工艺口径，UT252P（340℃）只到 PEEK 级，P800（385℃）够到 PEK、压不住 TPI（388℃）——**365℃ 以上熔点段我们目前是三家唯一覆盖**。
  - ②实证层：PEEK 基体系（MoS₂／h-BN／SCF 增强）已批量打印、性能数据与三大应用场景全链条验证（P8/P11/P13-15 互证）。
  - ③路线层：闭环调控授权专利（ZL202411862358.5）是**材料无关的温度场控制方法**——换材料＝换工艺包，装备平台自然外溢，这正是"材料×装备双自主"的装备侧含义。
- **Q：PI 在 LPBF 里公认难烧结，你们凭什么？**——难恰恰在温场：TPI 高熔点＋高熔体黏度，最怕热累积与温度梯度；多区域协同温控＋仿真平台正是为这个瓶颈而生（本页左下卡），这是能力对口而非空喊。
- 事实核对责任：以上涉及"三家唯一覆盖"的对比表述，答辩前按 Q2/Q4 确认口径后使用；若无把握，退为"覆盖域更宽"。
