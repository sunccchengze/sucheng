## 0. 三句话结论

1. **结构判定：把现有 P2（挑战页）与 P3（材料+装备方案页）重拆成两页**，页数仍为 22 页：
   **新 P2 = 材料页**（PEEK优势 → 自润滑复合材料优势 → 均质构件矛盾 → 梯度构件需求）；
   **新 P3 = 装备/工艺页**（PEEK成形难点 + 传统加工劣势 → LPBF制造自由度更高 → 引出第三项技术优势）。
   现有 P3 的材料半个版块整体上移进 P2，P3 的"传统工艺劣势 + LPBF"整个版块扩成 P3 正题。
2. **三处必须新写的页面级"主旨句"**（网评一眼看懂的主叙事）：P2「选对材料——PEEK基自润滑复合材料为极端工况而生」；
   P3「为什么用LPBF——以更高制造自由度突破'同材同能』」。这两句是李亚洲第⑥条的直接落地。
3. **一条铁红线**：P3 写"PEEK 材料高熔点/难成形"可以，**400℃ 只能写"腔体温度上限"**，绝不能写"PEEK 预热 400℃"；
   沿用前轮判例（PEEK 熔点≈343℃，400℃=设备腔体控温上限，答辩预热实测 320/335℃）。

## 1. 为什么这样拆——叙事逻辑

- 现有 P2 是"挑战页"（传统润滑缺陷 + 均质构件反例 + 成形失败图），信息偏"问题"；
  现有 P3 是"方案页"（PEEK 材料 + 传统工艺劣势 + LPBF），**一页塞了两件大事**：材料优点 与 工艺/装备。
- **李亚洲的诉求＝把两件大事摊开成两页**：第二页专心讲"材料为什么行"（PEEK + 自润滑复合材料），
  第三页专心讲"为什么非要用 LPBF"（成形难点 + 传统加工劣势 + 制造自由度）。这才是"网评让他们看清楚"。
- "梯度构件成形"正好当**第二页的收束钩子**（均质构件同材同能 → 不同位置不同性能需求 → 需要更高制造自由度的成形路径），
  把 P2 落到 P3 的引子，而不是让 P2 停在"问题"上。
- "第三项技术优势"＝结构端的**自适应摩擦-力学耦合超材料/梯度结构**（现有 P10）。P3 底部一句话点出，
  "LPBF 高制造自由度恰好支撑按功能分区、梯度结晶、局部拓扑"——把 P3 与 P10 串成一条链，评分点连续。
