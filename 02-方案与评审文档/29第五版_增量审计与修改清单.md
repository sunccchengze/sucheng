## 一、四类跨页硬冲突现状（T0，先统一再逐页改）

### 1. 工艺路线（P3 / P4 / P12）
- 现状：P3 “自主研制特种成形装备——HT-SLS成形机” 与 “高温LPBF” 并存；P4 把 EOS P800（激光烧结路线）、UT252P（SLS）、LPBF-400（LPBF）放同一表；P12 同上。
- 改法（P3 加一行定义，一字不动原图也可）：
  > `HT-SLS：团队早期高温激光烧结路线（历史型号）；2021 年起全面转入高温 LPBF 激光熔化路线，现役机型 LPBF-400。`
- P4/P12 表加“工艺路线”列：EOS P800＝激光烧结 / UT252P＝SLS / LPBF-400＝LPBF；表下注一行：`三家工艺路线不同，仅按公开指标并列，不等同实测对比。`

### 2. 温度口径（P4 / P6 / P10 / P12 / P25）
- 现状：P4 “成形腔最高温 385（EOS）/340~380”，P12 “385/380/400”，P6/P10 “突破400℃”，P25 “<0.42℃”。
- 改法：建立五词字典，全篇只许用这五个词（见第四节数字真值表）：
  - `腔体最高温度`（能力值）：400℃（自测）
  - `粉床稳定成形温区`（工作值）：310–330℃（答辩 P29 稳定阶段曲线）
  - `温场平均偏差`：<0.42℃（＝0.4217℃，答辩 P36；**不得混用 P37 的 0.5009℃**）
  - `温场极差降幅`：55.45%（答辩 P36）
  - `闭环控制达标率`：96.00%（答辩 P36，需注明判定阈值）
- P4 表头“成形腔最高温”先与 P12 同步为“腔体最高温度（℃）”；`340~380` 必须拆明：华曙 2025 年报公开口径是 **340℃**，PPT 在版写 380℃——二选一并注来源（原厂资料复核后再定）。

### 3. 材料适配边界（P9 / P10 / P12 / P21）
- 现状：P10 “适用于高熔点聚合物如PEEK、PI”；实证只有 MoS₂/PEEK、h-BN/PEEK。
- 改法：`已验证：PEEK 基体系；目标适配：PI 等高熔点聚合物`。凡超出 PEEK 基实测的表述一律加“目标适配”。

### 4. 4.04 MPa 定义（P12）
- 现状：下表行名“成形构件批次强度波动 ≤4.04MPa”。
- 改法（答辩 P41 原始口径）：行名改
  > `多次打印拉伸试样最高强度最大差值（MPa）`
  数值 `16.03 → 4.04`，表下注：`12 wt.% MoS₂/PEEK、N 个平行试样、自由打印 vs 控温打印对比（答辩 P41）`。不得泛化为“构件批次强度波动”。

### 5. 应用证据分级（P15 / P16 / P18）
- 见逐页清单，统一要求：每个百分比必须能答出“谁测的、测了什么、与什么比、是否为实物件、寿命如何加速换算”。

### 6. 商业主语链（P17 / P20 / P21 / P22 / P25）
- 现存的连续材料主线：P17“材料、装备双百亿”→P20“材料销售”→P21 首卡“高性能PEEK基自润滑复合粉末”→P22 PEEK 原料供应链→P25“PEEK基自润滑复合粉末”。
- 改法：按工单既定口径全线 `材料→耗材`（P17/P19/P20/P21/P22），并把叙事顺序调整为 **装备销售 → 打印服务 → 构件 → 配套耗材**；耗材统一定性为“装备生态配套”。

## 二、逐页“还剩什么 / 怎么改”（T0=提交前必做，T1=强烈建议）

### P1 / P26 标题与收口（T1）
- 现状：仍为“高端装备自润滑复合构件国产化开拓者”；P26 收口句没有把“装备→构件成绩单”的因果写出来。
- 改法（二选一，全篇统一）：
  - A 案（团队自用）：`特种高温增材制造智能装备国产化开拓者`（与 P1–P6 精修方案首页标题同源）
  - B 案（保守）：标题不动，P26 收口句改为 `以自研高温 LPBF 装备和闭环工艺，稳定成形高性能复杂构件`；副标一行：`PEEK 基自润滑复合材料：当前已验证应用场景`。
- 验收：P1 / P17 / P21 / P26 主语链必须一致。

### P2 开场（T0）
- 现状：油脂/涂层润滑失效开场，把评委带入材料替代润滑赛道。
- 改法（标题+三卡结构，原问句保留）：
  - 主标：`高温聚合物复杂构件成形装备的三大瓶颈`
  - 卡1 `超高温密闭腔体`：PEEK 等高温聚合物需 400℃级粉床热环境，腔体控温与隔热是首要瓶颈
  - 卡2 `热场原位感知缺失`：缺乏点面协同测温，温度场“看不见、控不住”
  - 卡3 `多区闭环调控难`：开环分区控温热累积明显，构件翘曲结块时有发生
  - 底部问句维持：`如何在真空无油、巨大温差的极端工况中，突破成形装备高精度、高稳定、智能化的制造？`
  - 补一行小字：`高端装备运动构件的自润滑需求，是这套装备的首个验证场景。`
- 验收：开场能自然接到 P3/P4 的装备问题，而不是 P9 的配方设计。

### P3 路线定义（T0）
- 现状：HT-SLS 与 LPBF 并存（见第一节 1 条）。
- 改法：按第一节 1 条加定义行；若团队无法证明 HT-SLS→LPBF 是同一路线的演进，删除 HT-SLS 字样，只保留 LPBF。右下“装备赋能”已改好（v5 已落位）。

### P4 市场与对标（T0）
- 现状：市场把 LPBF 与 PEEK 并列；表格把三种工艺路线放同一竞争口径；“340~380℃”无定义；EOS P800 标为激光烧结机。
- 改法：
  - 拆两块：左“装备/场景市场”（LPBF 装备市场、商业航天/人形机器人/核电场景），右“耗材市场”（PEEK 粉末，作为配套口径）；
  - 表加“工艺路线”列与“数据口径”列（公开资料/自测），温度按第一节 2 条字典改写；
  - 数字一律注来源、定义、时间点：`LPBF 276.59 亿（2032，贝哲斯）、PEEK 131 亿（2031，中研普华）`；
  - UT252P 温度冲突必须复核原厂资料（340 年报口径 vs 380 在版），复核前**不写 380**。

### P5 闭环路径（T1）
- 现状：四项路径成立，但“强化学习指导动态调控”像算法标签，没有状态/动作/执行器/物理反馈闭环。
- 改法：补一个最小闭环图注（可放原流程图旁）：
  > `点/面测温 → 状态矩阵 → PPO 输出动作 → 多区加热功率调节 → 下一周期温度反馈`
  并注明：采样周期、控制对象、动作边界、`仿真验证` 与 `实机验证` 分开标注；实机闭环未跑通就不得包装为装备实测。

### P6 指标卡（T0）
- 现状：“突破400℃”“降至0.42℃以下”“达标率96%”“尺寸误差±1%”缺定义与主语。
- 改法：每张卡加“指标名+定义+场景”三行，数值按第四节真值表：
  - `腔体最高温度 400℃`（腔体能力；粉床稳定成形温区 310–330℃ 见 P10）

  - `闭环控制达标率 96%`（达标周期占比，注明判据与工况）
  - `成形构件尺寸误差 ±1% 以内`（与 P12 同源，注明构件类型与样本数）
