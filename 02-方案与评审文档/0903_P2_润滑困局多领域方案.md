## 0. 三句话结论

1. **P2 全面做减法**：现 P2 混了两件不相干的事——「润滑困局」（应留）和「成形失稳/梯度打印」（应走）。
   本方案把**均质构件/齿面齿芯/分区梯度打印整块**移去 P3（P3 梯度成形块已承担），把**翘曲/粉层开裂/345℃/孔洞/高预热难度整块**移去 P4（P4 成形难点块已承担）。删净后 P2 只剩一件事：**润滑困局**。
2. **P2 做加法的是「多领域」**：新的视觉主体是**空天 / 机器人 / 核能 / 深潜 / 国防军工五领域困局矩阵**——
   P2 从"一个齿轮/一个工况"升维成"跨领域行业级瓶颈"，评委 3 秒读到"这不是小问题，是普遍难题"。
3. **P2 结尾一杯"如何破局"**：一句收束＋箭头「见 P3/P4」，与已定稿的 P3"材料之答"、P4"工艺之答"形成
   「困局→材料→工艺」完整三步，且不重复 P3/P4 已展开的任何内容。

## 1. 为什么"只讲困局 + 多领域"——叙事逻辑

- **评委第一眼**：现 P2 上半是均质齿面齿芯、下半是翘曲 345℃，右下才是传统润滑缺陷——信息打架，
  评委读到的印象是"技术问题很多"，而不是"润滑是普遍瓶颈"。删掉非润滑内容后，P2 让评委 3 秒看清"差在哪"。
- **多领域是"产业价值 + 项目创新"的发分点**：网评无讲解，评委只靠标题与图记忆。五领域矩阵＝
  "这问题空天有、机器有、核能有、深海国防也有"——一个"行业级通用瓶颈"的视觉证据，直接垫高立意。
- **与全文闭环**：P14/P15 应用案例（149厂/优艾智合/中物院）、P20 未来展望（航空/机器人/核电/深海/国防）都在这五个领域，
  P2 立"困局"，后面是"破局→案例→蓝图"。梯度/成形细节不抢 P2，因为 P3/P4 已有专属页。
