## 2026-08-29 视觉审核四件套程序体检（与目视互补，可复用）
纯目视会漏、纯脚本会假阳性；这四项 + 14 处裁图把问题数翻倍：
1. **越画布对象**：逐图 `get_image_bbox` 与 (960,540) 比 x0<0/y0<0/x1>W/y1>H，并算溢出比例，据此分"必修／清理源文件"两类。
2. **小字**：span size<8pt 逐页列（P21=5pt、P6=7pt 在 120dpi 目视完全看不出）。
3. **红色矢量批注**：`get_drawings()` 筛 color/fill 为 r>0.55,g<0.4,b<0.4 且尺寸>5pt，逐页给坐标——**发现"改稿批注忘删"的唯一可靠手段**。
4. **"表格是不是贴图"**：拿表内任一关键词查 `page.get_text()`，查无＝贴图（P18 因此暴露：贴图表格＝投屏发糊＋无法核对＋无法改，属高危）。
外加：跨页数字用"一词一行"正则扫（0.42/96%/±1%/400/0.05…一次跑完 26 页），比逐页读快且不漏；同一指标出现 3 种页码组合即打架证据。
