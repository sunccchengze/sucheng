## 特别提醒

- **01、04、11、16 这四张是这次找到的最强素材**——分别是你们自研装备的实拍、真实3D热力扫描图、
  真实监测软件截图、真实对照试验照片，比之前我从网上找的或AI生成的都更贴合"这就是我们自己做的"
  这个叙事，建议优先替换进背景第一/二页。
- 07 号图（不同功率下试样形貌对比）是目前为止**唯一能精确对应**0811建议里"PEEK/h-BN、PEEK/MoS2
  试样...对比图"这句话的真实素材，建议替换掉之前用的通用翘曲照片。
- 19、20 两张标了"参考图"，因为它们的画风（干净的示意图/网图质感的成品照）看起来不像是你们
  自己拍摄绘制的，用之前建议你确认一下来源，如果是引用的公开资料，公开路演材料里最好标注引用。
