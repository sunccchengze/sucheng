## 2. 优先级层级（冲突时高层否决低层）

   追溯到"仓库内 PPT 原始出处"或"检索得到并标注来源的公开数据"，两者严格分开标注。
4. **判例式负向记忆**：`.memory/ERRORS.md` 中记录的教训不得重犯。

## 3. 统一工作循环（Think → Spec → Implement → Verify）

### A. 定义问题
- 把"背景四页改一改"这种模糊需求，转成具体的**版式规格**：每页标题、左右分栏内容、
  底部结论句、需要保留/替换/新增的图片。
- 参照 `背景修改建议-0811.docx` 原文逐条对齐，不脑补孙承泽没提到的要求。

### B. 建立证据
- 先读仓库已有的三份原始材料：`挑战杯最新0529(1)_副本.pdf`（省赛答辩全文）、
  `背景四页ppt.pptx`（当前四页原始版式与素材）、`背景修改建议-0811.docx`（修改方向）。
- 外部事实（市场规模、竞品参数、政策原文）一律经情报检索专家核验，标注来源与检索时间。

### C. 实施最小变更
- 优先复用已有素材（原 pptx 内嵌图片、图表），非必要不重新生成图片。
- 页面结构、配色、字号与省赛版保持统一，不引入新的设计语言。

### D. 验证并交付
- 红队五官逐项过一遍（答辩追问 / 数据真实性 / 去 AI 味 / 信息设计 / 视觉一致性）。
- 交付前用 `python-pptx` 回读一遍生成的 PPTX，确认文本无乱码、图片无变形拉伸。

## 4. 本项目专属技术叙事路由（材料—装备—结构—制造）

| 技术环节 | 核心论证点 | 对应负责专家 |
|---|---|---|
| 材料端 | PEEK 基自润滑复合材料配方定制、摩擦系数 <0.10 | 材料摩擦学专家 |
| 装备端 | 高温 LPBF 多区域协同温度场闭环调控、成形翘曲率 <0.3% | LPBF 装备与温控专家 |
| 结构端 | 摩擦-力学耦合自适应超材料、仿生刺状织构 | 结构仿生设计专家 |
| 制造端 | 从概念到成品的全流程服务、四条盈利线 | 产业应用与商业化专家 |

与《大国重器》式的装备叙事定位不符；三份修改建议已经明确给出新的三页结构（详见
`03-专家团与技能路由/02-背景页改造工作法.md`）。
